## 🤖 What is BROM?

**BROM** — **B**annar **R**obotics **O**perations **M**anager — is Bannar Robotics' internal organization-management and project-communication application.

Before BROM, the organization relied heavily on **WhatsApp and email** to coordinate work. That created real problems:

- Important information was scattered across WhatsApp chats and email threads
- Project progress was hard to track
- Task assignments were easy to lose track of
- Work-related messages got mixed in with unrelated conversations
- There was no single place to see how the organization was doing
- Clients had to ask around just to get a status update
- Project Managers struggled to keep a structured overview of their projects and teams

BROM gives the organization one dedicated place for **projects, tasks, progress tracking, meetings, and project-related communication.**

Three groups use BROM day-to-day:

| Role | Main Responsibility |
|---|---|
| 👨‍💼 **Project Manager** | Manages assigned projects, tasks, deadlines and meetings |
| 👷 **Team Member** | Completes assigned tasks and updates progress |
| 🤝 **Client** | Monitors project progress and communicates regarding projects |

A **System Administrator** sits above all three, managing accounts, roles, and projects.

## 💡 Why BROM?

> **BROM does not simply provide another messaging platform. It organizes organizational communication around the actual work being performed.**

**WhatsApp** → general, personal communication.
**BROM** → organization-related communication, projects, tasks, meetings, progress, and updates.

BROM isn't meant to replace WhatsApp entirely — it exists to give organizational work a dedicated, trackable home instead of letting it get lost in general chat.

## 🚀 Getting Started

Every BROM user goes through the same onboarding process — no matter their eventual role.

> **You cannot create your own BROM account.** Every account is created by the System Administrator.

### Step 1 — Contact the System Administrator
Reach out to your System Administrator and provide your email address.
> *"This is my email address. Please create my BROM account."*
- Self-registration is **not** available.
- The System Administrator creates the account on your behalf.
- Your email address becomes tied to your account.

## 🔐 Temporary Password & Security

The password you receive from the System Administrator is a **temporary, one-time login password**.

1. You receive the temporary password.
2. You sign in with it.
3. The temporary password is immediately invalidated.
4. If you log out, that same temporary password cannot be reused.
5. You must contact the System Administrator for a new one.

> This ensures an old temporary credential can never be reused to get back into the account later — each login requires a fresh, Administrator-issued password.

```
[SCREENSHOT: Login screen showing email and temporary password]
IMAGE_URL_HERE
```

**Flow:**

```
Receive Password  →  Sign In  →  Password Invalidated  →  Logout  →  Request New Password
```

### Task Progress System

BROM uses a simple five-level progress system:

| Level | Progress |
|---:|---:|
| 1 | 20% |
| 2 | 40% |
| 3 | 60% |
| 4 | 80% |
| 5 | 100% |

```
 1        2        3        4        5
20%      40%      60%      80%     100%
 ●────────●────────●────────●────────●
```

Select the level that matches how complete you believe the task is — Level 1 for roughly 20% done, Level 5 when it's complete.

## ❓ FAQ

**Can I create my own BROM account?**
No. Your account must be created by the System Administrator.

**Can I choose my own role?**
No. Your role is assigned by the System Administrator.

**What happens to my temporary password after I log in?**
It becomes invalid and cannot be reused.

**What happens if I log out?**
You must request a new temporary password from the System Administrator.

**Can clients monitor project progress?**
Yes — Clients can monitor the progress of projects assigned to them.

**Can Team Members update their task progress?**
Yes, using the five-level progress system.

**Can Project Managers schedule project meetings?**
Yes — project-level meetings with an external meeting link.

**Is BROM intended to replace WhatsApp?**
Not necessarily. BROM provides a dedicated environment for organizational and project-related communication.
